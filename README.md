# NyaaSkills

Skill and Agents I use.

Add plugin to `.claude/settings.json`
```json
{
	"enabledPlugins": {
		"switchboard@atelier-nyaarium": true
	},
	"extraKnownMarketplaces": {
		"atelier-nyaarium": {
			"source": {
				"source": "github",
				"repo": "atelier-nyaarium/claude-marketplace"
			},
		"autoUpdate": true
		}
	}
}
```
